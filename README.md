
# Kajiado County Website

## Project Description

This project is a county information website developed
using HTML5 and CSS3.

It provides information about Kajiado County,
its departments, services and contact details.

## Project Pages

- index.html - Home page
- about.html - About Kajiado County
- departments.html - County departments
- services.html - County services
- contact.html - Contact information and form

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Responsive design
- Formspree contact form

## Website Features

- Navigation between pages
- County information
- Department information
- County services
- Contact information
- Contact form
- Responsive layout
- CSS hover effects

## How to Run

1. Open the County-Website folder in Visual Studio Code.
2. Open index.html.
3. Run it using Live Server or a web browser.
4. Use the navigation menu to visit other pages.

## Contact Form

The contact form uses HTML and Formspree.

The Formspree endpoint must be configured
before messages can be submitted successfully.

## Project Purpose

The project demonstrates HTML structure,
CSS styling, navigation, forms,
responsive design and website development.
